# Groupr Website

A modern grocery delivery website for NYC residents, built with Vite, React, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

- `src/components/ui/` - Reusable UI components (Button, Logo, Input, etc.)
- `src/components/layout/` - Layout components (Navbar, Footer)
- `src/components/sections/` - Page sections (Hero, Products, FAQ, etc.)
- `src/pages/` - Page components

## Build Plan

See `BUILD_PLAN.md` for the complete component build order and design tokens.

## Design System

Colors, typography, and spacing are defined in `tailwind.config.js` based on the original design files.
