# Post-Login Catalog

**We are building here.** This is the post-login catalog / “All Products” experience.

- **Stack:** Vite + React + TypeScript + Tailwind
- **Design source:** Borrow components, design tokens, and assets from **`../groupr`** (reference only; we don’t build inside groupr).
- **Reference files in this folder:** `1.txt` (React layout), `2.txt` (CSS), `3.txt` (global CSS) describe the target UI.

Components will be implemented in this repo; Groupr is used for inspiration and to copy patterns (e.g. Navbar, Footer, Button, ProductCard, Tailwind theme).
